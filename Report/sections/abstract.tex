\chapter*{Abstract}

This report presents the design and development of an automated network self-defense system called \textbf{Automated Network Self-Defense System (ANSDS)}. The project was carried out during a summer internship at the National Cybersecurity Agency (ANCS).

The main objective is to design a system capable of automatically detecting SSH attacks, sending real-time alerts through Telegram, and automatically blocking the attacker's IP address on a Cisco router using the Netmiko library.

A laboratory environment was developed using GNS3, including a Cisco router, a Cisco switch, an Ubuntu Server, a Kali Linux machine, and Internet connectivity. This platform makes it possible to reproduce attack scenarios and validate each phase of the project.

Future work includes SSH traffic analysis with Wireshark, attack detection, automated response mechanisms, and complete system validation.

\textbf{Keywords:} Cybersecurity, SSH, GNS3, Cisco IOS, Netmiko, Wireshark, Python, Network Self-Defense.
