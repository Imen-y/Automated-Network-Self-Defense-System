# Automated Network Self-Defense System (ANSDS)

## Project Goal

Design and implement an automated network defense system capable of detecting SSH attacks, notifying the administrator in real time, and automatically isolating the attacker using Cisco network automation.

---

# Development Methodology

Each project phase follows the same workflow:

1. Technical implementation
2. Technical validation
3. Screenshots
4. Documentation
5. LaTeX report
6. Git commit
7. GitHub push
